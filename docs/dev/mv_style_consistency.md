# Стандарт консистентности AI-музыкальных клипов (стиль / палитра / герой)

> **Статус:** обязательный стандарт для всех production-запусков анимационных клипов (balloon_frames, poka_beatsya_frames и будущие).
> **Применяется:** на этапе кейнфреймов (t2i/i2i), оживления (i2v) и финальной сборки.
> **Источники приёмов:** общепринятая схема «canonical character reference → reference-conditioned i2i → i2v» (аналог IP-Adapter / `--cref` из Midjourney; см. [IP-Adapter](https://morphic.com), [ComfyUI IPAdapter walkthrough](https://ordinaryanimator.com), [DomoAI MV workflow](https://www.domoai.app/make/post)).

## 〇、Три железных правила

1. **Один стиль и одна палитра на весь клип.** Во всех промптах кейнфреймов — дословно один и тот же style-блок (одна строка в начале промпта) + один и тот же список цветов палитры. Off-palette цвета — в negative_prompt (`daylight, warm color cast, oversaturated, ...` — по ситуации).
2. **Герой максимально похож между кадрами.** Для каждого кадра с героем генерация идёт **i2i с референсом** (канонический кадр героя), а не чистым t2i. Описание героя повторяется в промпте **дословно одной и той же фразой** (character canon line).
3. **Референсы везде, где можно.** t2i/i2i кейнфреймов — `reference_image` с каноном героя; i2v — `reference_image` с кейнфреймом сцены; ревью — контакт-лист всех кадров одним изображением.

## 一、Character canon и карта персонажа (Character Turnaround Sheet)

- **Обязательное создание карты персонажа (Character Sheet / Model Sheet)**:
  До начала генерации сцен создаётся единая карта персонажа со всеми ракурсами:
  1. Крупный план лица анфас (Front Face close-up)
  2. Три четверти лица (3/4 Face View)
  3. Профиль (Side Profile)
  4. Вид сзади (Back View)
  5. Полный рост с канонической одеждой и реквизитом (Full Body)
  Файл сохраняется как `character_sheet.png` (и отдельные срезы `char_face_front.png`, `char_face_profile.png`).
- **Character canon line** — строго фиксированная фраза-описание персонажа, вставляемая в каждый промпт без единого изменения слова.
- **В Google Flow / Veo**: Карта персонажа загружается в Assets проекта и через «Zum Prompt hinzufügen» жестко привязывается ко всем промптам генератора.

## 一.1、Карта ключевых предметов (Recurring Props Sheet)

- **Обязательное создание карты повторяющихся предметов**:
  Если в клипе есть сквозные реквизиты (фонарь, сердце, кинжал, маяк, амулет и т.д.), для них ДО создания сцен генерируются изолированные эталоны (`prop_<name>_ref.png`) с фиксированным материалом, формой и источником света.
- **Prop canon line**: неизменная строка описания предмета, включаемая во все промпты сцен с этим предметом.
- **Главный пайплайн проекта** (см. `.agents/rules/mandatory_reference_pipeline.md`):
  1. Создать карту персонажа и карту предметов.
  2. Создать картинки (кейнфреймы) для ВСЕХ отрывков с референсами (i2i).
  3. Проверить единый контакт-лист.
  4. Создавать видео по этим картинкам, ВСЕГДА прикладывая референс кадра и карту персонажа/предметов.


## 二、Style block (style/palette блок)

- Style-блок — первая часть промпта до `|` (формат `prompts_*.txt`), **дословно одинаков** во всех кадрах: художественная техника + палитра (именованные цвета) + фактуры + композиция 16:9.
- Палитра фиксируется 2–4 именованными цветами (пример: `deep indigo and bone-white duotone, single warm golden light accent`). Цвета героини/реквизита входят в canon line, не варьируются.

## 三、Ревью-петля (обязательная)

1. После генерации партии кадров — контакт-лист: `ffmpeg -framerate 1 -i scene_%02d.png -filter_complex "scale=480:-1,tile=4x5:padding=4" -frames:v 1 contact_sheet.png`.
2. Визуальная проверка ВСЕХ кадров: соответствие сцене, стиль/палитра, дефекты (текст, watermark, анатомия, лишние объекты), **сходство героя с каноном**, непрерывность потока между соседними сценами (светлеет/темнеет по сюжету).
3. Брак перегенерировать точечными промпт-фиксами (i2i с референсом), повторять петлю до APPROVE ALL. Только потом запускать i2v.

## 四、i2v и сборка

- i2v: `reference_image=@scene_XX.png` (кейнфрейм сцены) + motion-промпт из «словаря движения» (только свет/погода/пульс; люди и камера неподвижны) + **общий фиксированный negative prompt** на все клипы.
- Длительность i2v ≥ таргета сегмента; финал — подрезка до таргета, конкатенация, наложение MP3 (`-shortest`).
- После сборки — просмотр финала: склейки на границах секций, палитра стыков, герой не «моргает» личностью между сценами.

## 五、Готовые скрипты-образцы

- Генерация партии: `poka_beatsya_frames/gen_scenes.sh` (формат `style|scene`).
- Точечная перегенерация i2i с референсом: `poka_beatsya_frames/regen2_consistency.sh` (`curl -F "reference_image=@poka_beatsya_frames/character_ref.png" -F "negative_prompt=..."`).
- Сабмит/поллинг/сборка: `poka_beatsya_frames/submit.sh` / `poll.sh` / `assemble.sh`.

## 六、Чек-лист перед запуском i2v

- [ ] Style-блок дословно одинаковый во всех промптах
- [ ] Character canon line дословно одинаковая во всех сценах с героем
- [ ] Все кадры с героем сгенерированы i2i от `character_ref.png`
- [ ] Контакт-лист проверен: стиль/палитра/герой/дефекты/непрерывность — APPROVE ALL
- [ ] Negative prompt един для всех i2v-задач
