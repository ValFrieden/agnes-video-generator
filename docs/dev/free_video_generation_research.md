# Где и как бесплатно генерировать видео — исследование

> **Дата:** 2026-10-10. **Заказ:** «найти, где и как генерировать видео бесплатно» (контекст: upstream agnes-video душится очередями; ищем альтернативы для пайплайна клипов).
> **Метод:** Perplexity MCP в момент исследования недоступен (сетевые 500) — использован WebSearch (RU/EN) + проверенная база знаний. Лимиты freemium-тарифов меняются часто — перед использованием перепроверять на сайте сервиса.

## 1. Потребительские сервисы с бесплатным тарифом (web/mobile)

| Сервис | Бесплатно | i2v | Качество/нюансы |
|---|---|---|---|
| **Kling AI** (klingai.com) | ежедневные кредиты (~66/день) | ✅ | топ-качество движения; watermark на free; медленная очередь в пик |
| **Hailuo / MiniMax** (hailuoai.video) | ежедневные генерации | ✅ | хорошее движение, watermark |
| **Pixverse** (pixverse.ai) | ежедневные кредиты | ✅ | быстрый, эффекты, watermark |
| **Pika** (pika.art) | месячные кредиты | ✅ | стилизация, watermark |
| **Vidu** (vidu.studio) | месячные кредиты | ✅ | неплохая консистентность персонажей |
| **Luma Dream Machine** | ограниченные месячные генерации | ✅ | плавная камера |
| **Runway (Gen-3/4)** | разовые стартовые кредиты | ✅ | дальше только платно |
| **Sora (OpenAI)** | через подписку ChatGPT; в app — лимитированные бесплатные генерации (региональные ограничения) | ✅ | топ-реализм |
| **BotHub** (bothub.chat) | ежедневный бесплатный лимит, агрегатор (Kling/Veo/Seedance и др.) | ✅ | RU-доступ удобный; один интерфейс на много моделей |
| **Pixlr / Vivideo / Kapwing** | freemium, watermark | ✅ | лёгкие, для соцсетей |

**Вывод для ручной работы:** бесплатные ежедневные кредиты Kling + Hailuo + Pixverse + BotHub в сумме дают ~10–20 клипов в день без оплаты — достаточно для клипа из 22 сцен за 2–3 дня ручной работы. Все принимают кейнфрейм как первый кадр (image-to-video) — наша раскадровка совместима напрямую.

## 2. Бесплатные API / автоматизация (для пайплайна как у нас)

1. **Локальные open-source модели (своя GPU):**
   - **Wan 2.2** (Alibaba, Apache-2.0) — t2v+i2v, 5B (≈8–12 GB VRAM с квантованием) и 14B (24 GB+); лучшее открытое качество движения.
   - **LTX-Video** (Lightricks) — очень быстрый, реалтайм-класс; 12 GB хватает.
   - **CogVideoX-5B**, **HunyuanVideo**, **Mochi-1**, **Open-Sora** — альтернативы.
   - Движок: **ComfyUI** (готовые i2v-workflows, поддержка контрольных сетей).
   - Наш пайплайн совместим: генерация = HTTP к локальному ComfyUI API вместо agnes-video; кейнфреймы/промпты те же.
2. **Бесплатные GPU-облака** (если своей GPU мало): Google Colab (бесплатный T4), Kaggle Notebooks (≈30 ч/нед T4×2/P100), Lightning AI free tier, HuggingFace Spaces ZeroGPU (демо Wan/LTX доступны через `gradio_client` — программная автоматизация с бесплатной квотой).
3. **Бесплатные хостед-API:**
   - **ModelScope API-Inference** (CN, бесплатный токен) — хостит Wan i2v; ближайший drop-in аналог нашего agnes-эндпоинта.
   - **HuggingFace Inference API** — бесплатные месячные кредиты (видео-модели ограничены).
   - **Google AI Studio** — Veo в бесплатном лимите для части аккаунтов/регионов.
4. **RU-агрегаторы:** BotHub (есть API, копеечный, есть ежедневный халявный лимит), Shedevrum (только приложение, без API).

## 3. Рекомендации для нашего пайплайна (по приоритету)

1. **Оставаться на agnes free** (уже работает: 2.5-flash отвечает, вопрос только очередей — queue-retry 3600 с решает). Ноль интеграционной работы.
2. **ModelScope Wan i2v API** — запасной автоматический путь (бесплатный токен, формат близок к нашему `/api/tasks/simple`; потребуется адаптер в `core/api/`).
3. **Локальный ComfyUI + Wan 2.2 5B / LTX-Video** — если GPU ≥ 12 GB; полная независимость от чужих очередей, консистентность через IP-Adapter/character LoRA.
4. Ручной гибрид: критичные сцены добирать бесплатными кредитами Kling/Hailuo (загрузка кейнфрейма как first frame) — вместе с нашим стандартом консистентности (`docs/dev/mv_style_consistency.md`) даёт то же качество.
