## Как вести эту базу
- Только проверенное: каждый пункт получен вживую или из кода. Догадки помечать «не проверено».
- Не дублировать код и историю git; писать то, что из них не видно (почему так решили, что не сработало, что любит автор).
- Один факт в одном месте; в остальных файлах давать ссылку.
- После каждой законченной сцены: обновить `production-log.md`.
