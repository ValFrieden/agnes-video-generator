# Факты о Google Flow (проверено вживую 27.10.2026)

Интерфейс немецкий, тариф Google AI Pro, режим «агент»: чат справа, поле запроса внизу. Выбор «картинка или видео» агент делает по тексту запроса.

## Лимиты и цены
- Veo 3.1 Fast: **20 кредитов за клип**; Ultra: 10. В 16:9 **только 8 секунд**. Выход всегда 16:9 (720p, ссылки на 1080p/4K только апскейл; 270p GIF).
- Картинки (Nano Banana 2/2.1): карточки цены нет, кредиты не списываются.
- Pro: 1000 кредитов в месяц (по справке Flow); баланс читается автоматически (`read_credit_balance`).
- Официальный API Veo: Fast 0,15 USD/с с звуком (8 с = 1,20 USD); нет цены Gemini API и лимитов в источниках; не реализован (`docs/flow_api_alternative.md`).

## Как ведёт себя агент
- Запрос должен начинаться однозначно: «Generate one image (not a video), 16:9…» или «Generate a video with Veo 3.1 Fast, 8 seconds, 16:9…» (`core/flow_prompts.py`).
- Запрос видео → карточка «Soll ich diese 1 Videogenerierung starten? Das kostet 20 Guthabenpunkte.» с кнопками Genehmigen / Immer genehmigen / Ablehnen. Только «Genehmigen».
- Невозможный запрос (6 с) → вопрос агента вместо карточки.
- Очередь: сообщение «generation has been scheduled and is waiting in the queue»; после рендера Flow сам открывает редактор клипа.

## Селекторы (единственное место: `core/api/google_flow_ui.py`)
- Поле запроса `.ProseMirror`; кнопка «+» `button[aria-label^="Bildelemente zum Prompt-Feld hinzuf"]`.
- Элементы меню ассетов: видимые `button` с именем файла и «Bild»; скрытая кнопка в подвале с тем же aria-label не должна совпадать.
- Чип референса в поле запроса: `button[aria-label^="Bildelement"]` с текстом `cancel` (миниатюры в истории чата без `cancel`).
- Кнопка отправки: **«Generierung starten» есть в нескольких экземплярах**; нужна последняя видимая и активная (`SUBMIT_CLICK_JS`).
- Скачивание: в редакторе клипа кнопка «Medien herunterladen» → пункт «720p Originalgröße».
- Аватар `a[aria-label^="Google-Konto"]` → в тексте «N Google Flow-Guthabenpunkte».
- Все селекторы цепочки прикрепления только ASCII (умлаут «ü» терялся при записи скриптов).

## Загрузки и права
- Загрузка файлов через файловый диалог (`Medien hochladen`); окно «Ich stimme zu» появляется редко, принимать только по слову автора.
- Загруженный и сгенерированный ассеты видны в меню рядом; нужное найти по имени файла.

## Что не проверено
- Стоимость Veo 3.1 Quality; сцены Flow (`Szenen`) как монтаж; пакетный API.

## Лимит вложений Flow (проверено 30.10.2026)
- В один запрос Flow прикрепляется не больше **двух** изображений. Третье не прикрепляется (в поле остаётся 2 чипа, движок пишет «expected 3 chips ... found 2»), запрос не уходит, кредиты не тратятся.
- Для сцен с двумя героями: keyframe делать с двумя листами (Маша + фея), в видео прикладывать keyframe + один лист (фея).
- Обход лимита (идея автора, 30.10.2026): склеить два листа в одну картинку (`masha_frames/props/refs_masha_fairy_v1.jpg`: сверху Маша, снизу фея, ffmpeg vstack 1376x1536). Тогда в запрос идут keyframe + эта общая референсия = 2 вложения.
