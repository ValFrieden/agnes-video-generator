# Übergabe: покадрово точная сборка клипа (07.11.2026)

**Цель.** В `scripts/assemble_full_mv.py` заменить сборку через `ffmpeg -f concat ... -c copy` (строки ~20–68) на покадрово точную: `trim=start_frame=…:end_frame=…, setpts=PTS-STARTPTS, fps=24` с перекодированием, границы шотов считать кумулятивно в кадрах, мастер-аудио накладывать последним без изменений. Причина: при `-c copy` склейки прыгают на ключевые кадры и съезжают с бита.

**Стан.** Исследование и правила готовы: `docs/knowledge/music-video-algorithm.md` (шаги 15–17), `ПРАВИЛА_КЛИПА.md` раздел 9, скилл `.claude/skills/music-video-director/`. Код ещё не трогали. Ничего не закоммичено.

**Следующий шаг.** Прочитать скрипт и соседние `scripts/assemble_*.py`, составить план (CLAUDE.md: план → согласие автора → код), затем исправить и проверить: ffprobe длительности и числа кадров результата против суммы шотов, отсутствие freeze-кадров (`freezedetect`), аудио совпадает с мастером.

**Ограничения.** Никаких стоп-кадров и `tpad clone`; `rm -rf` запрещён; коммит только по просьбе автора; хирургические правки.

**Файлы.** `scripts/assemble_full_mv.py`, `docs/knowledge/music-video-algorithm.md`, `ПРАВИЛА_КЛИПА.md`.
