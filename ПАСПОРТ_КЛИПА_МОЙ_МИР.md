4. **Кристальная кинематографическая картинка**:
   * Современная чёткость ARRI Alexa LF 8K.
   * **Категорический запрет на винтажное зерно, шум, муть и титры плёнки** (никаких надписей «Kodak Vision 5000T», жёлтых цифр таймкода и перфорации).
   * Без очков, рот закрыт.
   * Никаких лишних предметов у лица (руки в карманах куртки или естественно опущены).
5. **Пофрагментный регламент приёмки**:
   * Работа ведётся строго по одной сцене.
   * Каждая сцена сдаётся через контрольные стоп-кадры (25%, 50%, 75%) и утверждается пользователем до перехода к следующей.

## 5. ТЕХНИЧЕСКИЙ КОНВЕЙЕР И СКРИПТЫ

### 5.1. Модель замены лиц (Face-Swap Engine)
* **Библиотека**: `insightface 2.1` + `onnxruntime 1.30.0` (CPU/DirectML).
* **Модель детекции**: `buffalo_l` (путь: `C:\Users\Valeri\.insightface\models\buffalo_l`).
* **Модель замены лица**: `inswapper_128.onnx` (путь: `d:\Projects\VideoGenerator\tools\insightface_models\inswapper_128.onnx`).

### 5.2. Скрипт покадровой обработки видео
Любое сгенерированное видео обрабатывается скриптом покадровой пересадки:
```python
# Запуск обработки видео с фиксацией лиц Валерия и Героини
# python scripts/process_video_faces.py --input <raw_video.mp4> --output <final_video.mp4>
```
Тестовый запуск на Сцене 01 ([scene_01_final_valeri.mp4](file:///d:/Projects/VideoGenerator/moy_mir_iz_snov_frames/scene_01_final_valeri.mp4)) подтвердил 100% стабильность сходства без мерцания и артефактов.

### 5.3. Скрипты для следующей сессии
* [batch_face_swap_all_scenes.py](file:///d:/Projects/VideoGenerator/scripts/batch_face_swap_all_scenes.py) — пакетная пересадка лиц на статичные кадры.
* [regenerate_unified_wardrobe.py](file:///d:/Projects/VideoGenerator/scripts/regenerate_unified_wardrobe.py) — генератор статичных кадров с единым промптом гардероба.
* [submit_clean_scene1.py](file:///d:/Projects/VideoGenerator/scripts/submit_clean_scene1.py) — чистый шаблон промпта для генератора видео без зерна и посторонних предметов.
