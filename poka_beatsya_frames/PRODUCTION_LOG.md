## Хронология решений

1. **Анализ песни** (`analysis_poka/analyze_audio.py`): RMS-энергия по 0.25 с, границы секций, BPM≈90 (хав-тайм), текст из ID3-тегов. Запуск: `cmd //c "python -E analysis_poka/analyze_audio.py"` (Git Bash молча убивает python с импортами — обход через cmd + `-E`).
2. **Кейнфреймы v1** (17 шт, t2i, `gen_scenes.sh`): ревью контакт-листа → брак 3,4,6,9,12,15,16 (палітра/свет/силуэты) → `regen1.sh` с точечными промпт-фиксами → APPROVE.
3. **i2v v1** (19 задач, `submit.sh` + `poll.sh`, `clips/`): сабмит 11:00–11:05. Глюк: `printf %02d` с 08/09 как восьмеричными → seq08/09 досланы отдельно (десятичная конверсия `10#`).
4. **Замечание заказчика → стандарт консистентности** (`docs/dev/mv_style_consistency.md`, ссылка в AGENTS.md): один стиль/палитра на клип; герой одинаков; референсы везде.
5. **Канон героя**: `character_ref.png` = копия scene_02 (капюшон + длинное тёмное пальто + латунный фонарь). Continuity line: `the same hooded traveler in a long dark coat carrying a warm brass lantern as in the reference image`.
6. **i2i-перегенерация сцен с героем** (6,8,9,10,13,15,16; `regen2_consistency.sh`): герой стал единым с 1 итерации. Побочный эффект: стиль ушёл в «печатный» (плоская гравюра + рамка, царапины) — ближе к обложке-цианотипии, но возник раскол с фотореалистичными 1–5,7,11,12,14,17.
7. **Унификация стиля** (10 оставшихся кадров; `regen3_unify.sh`): новый style-блок `Vintage cyanotype storybook print, flat textured illustration, ... aged paper with bone-white border and scratched edges...`; сцены с героем — i2i от character_ref, без героя — t2i. Печатный стиль выбран целевым: стабильнее в i2v, роднее обложке.
8. **i2v v2** (`submit2.sh` + `poll2.sh`, `clips2/`): пересабмит всех 19 задач от v2-кейнфреймов; negative prompt расширен по Perplexity (flicker/ghosting/temporal-блок, см. optimization doc). v1-клипы = фолбэк.

## Известные грабли среды

- Git Bash молча убивает процессы python с тяжёлыми импортами → запускать через `cmd //c "... python -E ..."`; фоновые bash-задачи могут стартовать не из корня репо → в скриптах `cd "$(dirname "$0")/.."`.
- ffmpeg Windows-сборка без glob → паттерн `scene_%02d.png`.
- `printf "%02d" 08/09` в bash — восьмеричная ошибка → `10#`-конверсия или `for n in $(seq 1 17)`.
- MCP-инструменты с таймаутом 30 с: perplexity_research не успевает → perplexity_ask (medium context) успевает.
- **Upstream t2i + `negative_prompt` = мгновенный 400** (apihub /v1/images/generations); i2i (с reference_image) негатив принимает. Правило: negative_prompt для картинок — только в i2i-режиме.
- Реген 3 принял стиль «печатной гравюры с рамкой» как целевой: для детерминизма стиль-блок дополнен `aged paper with bone-white border and scratched edges`.
