# Auto Find-Skills Directive (Автоматический запуск find-skills)

> **Обязательное правило проекта**: Каждый раз после ввода пользователем любого промпта, вопроса или задачи агент **ОБЯЗАН автоматически запускать рабочий процесс скилла `find-skills`**.

---

## 1. Логика выполнения при каждом промпте

При получении любого пользовательского запроса:

1. **Анализ домена запроса**:
   - Выделить ключевые слова, технологии и предметную область (например: `character consistency`, `storyboard`, `voice acting`, `video editing`, `testing`, `frontend`, `audio`, etc.).
2. **Автоматический запуск поиска навыков (`find-skills`)**:
   - Выполнить поиск подходящих проверенных навыков через `npx skills find <ключевые_слова>` или обратиться к каталогу установленных/глобальных скиллов (`find-skills`).
3. **Оценка и интеграция**:
   - Если найден полезный навык с высоким числом установок (> 1K), предложить его установку пользователю либо применить описанные в нём техники и шаблоны для решения задачи.
4. **Прозрачный отчёт**:
   - Кратко уведомить пользователя о результатах проверки релевантных навыков для текущего промпта.
