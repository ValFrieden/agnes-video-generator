# Kling AI: Регламент анимации сторибордов 2×2 (Sequential Storyboard Morphing) и MCP Интеграция

> **Статус**: 🟢 Внедрено в проект VideoGenerator (v7.3)
> **Модели**: Kling AI MCP (`https://kling.ai/mcp`), Kling 2.6 / 3.0 (Video), Gemini 3.1 Flash Image / Kling Image 3.0 (Image)
> **Назначение**: Бесшовная генерация сложных видео-трансформаций без склеек на основе опорных сеток 2×2.

---

## 1. Архитектура интеграции Kling MCP

### 1.1 Авторизация и доступ
* Сервер: `https://kling.ai/mcp` (Streamable HTTP / JSON-RPC 2.0).
* Авторизация: **OAuth 2.0 PKCE** с авторизационным сервером `https://kling.ai/auth`.
* Скоупы: `generation.create`, `generation.read`, `account.credit.read`.
* Токены хранятся в `~/.claude/.credentials.json` (ключ `klingai`) и дублируются с заголовком `Authorization: Bearer <token>` в `~/.gemini/config/mcp_config.json`.
* Проверка баланса: инструмент `query_membership_and_credits`.

### 1.2 Ценовая политика и оптимизация кредитов (Золотой стандарт)
* **Standard 720p (5 секунд) = 10 кредитов**:
  - Базовый стандарт для 90% шотов.
  - Физика движения и траектории идентичны режиму Pro 1080p.
  - Позволяет делать сид-роллинг (до 3-4 дублей за цену одного Pro).
* **Pro 1080p (5 секунд) = 35 кредитов / (10 секунд) = 70 кредитов**:
  - Использовать только точечно для сверхкрупных планов (hero shots) при наличии дефицита микродетализации.
* **Апскейл**: 720p поднимается до 1080p/4K локально через наш `post_processor.py` / FFmpeg с нулевым расходом кредитов.

### 1.3 Автоматическое обновление OAuth-токена (Refresh Token Lifecycle)
* Срок жизни `accessToken` составляет ровно 3600 секунд (1 час).
* В структуру `~/.claude/.credentials.json` входит долгоживущий `refreshToken`.
* Эндпоинт обновления: `POST https://kling.ai/auth/token` (form-data: `grant_type=refresh_token`, `client_id`, `refresh_token`).
* При `expiresAt - now < 60s` или ответе `HTTP 401 Unauthorized` скрипт/агент выполняет автоматический refresh без повторного открытия браузера.

## 2. Методология «Сториборд 2×2 → Непрерывное видео Kling»

Методология решает фундаментальную проблему генеративных моделей (случайные блуждания и потеря контекста к концу ролика), задавая пространственно-временную карту (Latent Roadmap) из 4 ключевых фаз в одном изображении.

### 2.1 Структура сетки 2×2
Опорное изображение генерируется строго в формате сетки из 4 панелей без рамок и надписей:
* **Кадр 1 (Верхний левый / Top-Left)**: Начальное состояние ($t = 0$), зарождение материи/формы.
* **Кадр 2 (Верхний правый / Top-Right)**: Первая фаза развития ($t \approx 1.5s$), изменение формы/материала.
* **Кадр 3 (Нижний левый / Bottom-Left)**: Напряжение / кульминация процесса ($t \approx 3.5s$).
* **Кадр 4 (Нижний правый / Bottom-Right)**: Финальный результат / катарсис трансформации ($t = 5s$).

### 2.2 Формула промпта для генерации сториборда (Image-модели)
```text
A cinematic 2x2 grid storyboard, 4 sequential panels showing a continuous transformation of [ОБЪЕКТ/МАТЕРИАЛ], photorealistic, 8k, [СТИЛЬ СВЕТА]:
- Panel 1 (Top-Left): [Описание фазы 1]
- Panel 2 (Top-Right): [Описание фазы 2]
- Panel 3 (Bottom-Left): [Описание фазы 3]
- Panel 4 (Bottom-Right): [Описание фазы 4]
Consistent lighting, consistent background, clean seamless 2x2 grid, no borders, no frames, no text, no split lines.
```

### 2.3 Формула промпта анимации в Kling (`image_to_video` / `@image1`)
```text
@image1 — сториборд, сетка 2×2, 4 последовательных кадра. 
Следуй порядку: сверху слева → сверху справа → снизу слева → снизу справа. 
Каждый кадр должен последовательно становиться полноэкранным этапом одной непрерывной сцены. 
Не показывай сетку, границы панелей или коллаж.

[Переходы и трансформация]:
[Четкое описание того, как объект из кадра 1 перетекает в кадр 2, затем в кадр 3 и кадр 4]

[Бесшовность]:
Одна непрерывная сцена без склеек и смены локации. 
Плавное движение камеры [например, slow push-in / slow pan]. 
Все трансформации происходят постепенно и остаются видимыми в кадре. 
Сохраняй единый фон, свет и текстуры.
```

### 2.4 Защита от артефактов (Обязательный Negative Prompt)
Чтобы исключить риск того, что Kling покажет коллаж из 4 экранов вместо одного полноэкранного видео, **всегда передавать**:
```text
split screen, 4 panels, collage, grid, comic strip, borders, dividing lines, multi-view, picture-in-picture, watermark, text
```

### 2.5 Железный замок стиля серии (Style Lock via Master Reference I2I)
Чистый Text-to-Image (T2I) для серии сторибордов неминуемо приводит к дрейфу визуального стиля (дрейф оптики камеры, смена студийного/природного света, фактур и фонов).
* **Принцип одного мастера**: Выбирается один эталонный сториборд (Master Reference, например, одобренный пользователем кадр с нужной оптикой 35mm и окружением).
* **Привязка через `image_to_image`**: Все последующие сториборды серии генерируются **строго через `image_to_image`** с передачей URL эталона в `inputs: [{'name': 'image_1', 'inputType': 'URL', 'url': master_ref_url}]`.
* **Наследование в промпте**: В тексте промпта явно фиксируется: `strictly matching the exact photographic visual style, camera optics, natural lighting, and textures of image_1`.
* **Модель**: `gemini-3.1-flash-image` в Kling MCP поддерживает мультимодальную передачу `image_1` с разрешением до 2K (16:9).

### 2.6 Производственный протокол анимации сеток (The Slicing Pipeline)
* **Запрет прямой подачи сетки в I2V**: Подача цельного изображения 2×2 в качестве `first_image` заставляет диффузионную модель анимировать 4 квадранта на месте, создавая артефакт 4-оконного коллажа/видеонаблюдения.
* **Автоматическая нарезка панелей**: Сетка 2K (2752×1536) автоматически нарезается через FFmpeg (`crop=1376:768:x:y`) на 4 самостоятельных кадра 16:9 сверхвысокой четкости (1376×768).
* **Загрузка через `file_upload`**: Каждый нарезанный кадр загружается в CDN Kling через одноразовый тикет `file_upload`.
* **Ограничение `tail_image`**: Режим с двумя опорными кадрами (`first_image` + `tail_image`) аппаратно поддерживается Kling только в разрешении **1080p** (35 кредитов). В экономичном стандарте **720p** (10-15 кредитов) анимация выполняется от одиночного первого кадра с точным описанием трансформации в промпте.
